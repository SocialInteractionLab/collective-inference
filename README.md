# Natural Language Communication Enables Groups to Overcome Unrepresentative Private Evidence

This repository contains code, data, and analyses for experiments examining how communication modality affects collective inference in small social networks.

## Overview

Participants in groups of 4 estimated an underlying probability distribution based on limited private observations, then exchanged information through different communication channels (slider-only, unidirectional messaging, or interactive chat). We manipulated information quality along multiple dimensions to examine when natural language communication becomes critical for aggregation.

## Reproducing the Analyses

All reported statistics are produced by the Quarto notebooks and Python scripts below. Run them in order to reproduce every number and figure in the manuscript.

### Prerequisites

- **R** (>= 4.3) with packages: `tidyverse`, `lme4`, `lmerTest`, `tidyboot`, `emmeans`, `ggthemes`, `patchwork`, `broom.mixed`, `here`, `conflicted`
- **Python** (>= 3.9) with packages: `numpy`, `pandas`, `matplotlib`, `scipy`
- **Quarto** (>= 1.3)

Install R packages:
```r
install.packages(c("tidyverse", "lme4", "lmerTest", "tidyboot", "emmeans",
                    "ggthemes", "patchwork", "broom.mixed", "here", "conflicted"))
```

Install Python packages:
```bash
pip install numpy pandas matplotlib scipy
```

### Step 1: Experiment 1

```bash
cd analysis/exp1
quarto render exp1_main_analysis.qmd
```

Reads `data/exp1/PreregMergedGuesses.csv`. Produces all Experiment 1 statistics, figures (`figures/fig2.pdf`, `figures/fig3.pdf`), and the exclusion criteria robustness analysis.

### Step 2: Experiment 2

```bash
cd analysis/exp2
quarto render 1_data_cleaning.qmd        # produces exp2_clean_data.csv
quarto render exp2_main_analysis.qmd      # main analyses and figures
```

Reads raw data from `data/exp2/raw/` and coded messages from `analysis/exp2/message_data/coded.csv`. Produces all Experiment 2 statistics and figures (`figures/fig5.pdf`, `figures/fig6.pdf`).

### Step 3: Computational Models

```bash
cd models
python fit.py        # fits models to Exp1 data, produces fit_results.csv
python predict.py    # generates Exp2 predictions, produces figures/fig7.pdf
```

`fit.py` reads `analysis/exp1/exp1_clean_data.csv` (produced by Step 1) and outputs fitted parameters to `fit_results.csv`. `predict.py` reads those parameters and `analysis/exp2/exp2_clean_data.csv` (produced by Step 2) to generate model predictions.

## Repository Structure

### `/experiments`
[Empirica](https://empirica.ly/) experiment code for the web-based platform (client and server).

### `/data`
Experimental data organized by experiment (exp1, exp2) with raw Empirica exports and merged datasets.

### `/analysis`
Quarto notebooks (`.qmd`) serving as the single source of truth for all reported statistics:
- `exp1/exp1_main_analysis.qmd` — Experiment 1 analyses
- `exp2/1_data_cleaning.qmd` — Experiment 2 data preparation
- `exp2/exp2_main_analysis.qmd` — Experiment 2 analyses

### `/models`
Computational models of collective inference:
- `fit.py` — Fits Belief (DeGroot) and Evidence (count-based) models to Experiment 1 data
- `predict.py` — Generates Experiment 2 predictions from fitted parameters
- `fit_results.csv` — Fitted parameter values

### `/figures`
Publication-ready figures (PDF) generated by the analysis pipeline.

### `/stimuli`
Game generation scripts for Experiment 2 stimuli. See `stimuli/README.md` for details.
